IDA Pro + Codex + MCP

Connect IDA Pro to Codex on macOS.

A fast, practical guide for enabling the MCP plugin in IDA Pro and connecting it seamlessly to your VS Code and Codex environment.

Start Setup Read Guide

Prerequisites

What you need before getting started.

IDA Pro

Use a professional version of IDA (e.g., 9.4), the free edition will not work.

Python 3.11+

Make sure the Python environment is valid and configured for your IDA installation.

Codex / VS Code

Run Codex inside VS Code and connect it via the HTTP MCP server protocol.

Connection Steps

Follow these exact steps to configure your environment.

1

Activate IDA library

Terminal 
uv run "/Applications/IDA Professional 9.4.app/Contents/MacOS/idalib/python/py-activate-idalib.py"
2

Install dependencies

Terminal 
cd ida-pro-mcp
uv sync
3

Install the IDA plugin

Terminal 
pip install https://github.com/mrexodia/ida-pro-mcp/archive/refs/heads/main.zip
ida-pro-mcp --install
4

Choose transport

During installation, select Streamable HTTP (recommended) and Global (user-level).

5

Configure Codex in VS Code

JSON 
{
  "mcpServers": {
    "ida-pro-mcp": {
      "type": "http",
      "url": "http://127.0.0.1:13337/mcp"
    }
  }
}

Troubleshooting

Solutions for common issues.

No MCP tool available

Ensure IDA is currently running, a database is open, and the local server is listening on 127.0.0.1:13337.

Connection refused

Run this check to see if the server responds properly:

Shell 
curl http://127.0.0.1:13337/mcp
