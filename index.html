Overview

What you need

IDA Pro

Use a professional version of IDA, not the free edition.

Python 3.11+

Make sure the Python environment is valid for IDA.

Codex

Run Codex in VS Code and connect it to the HTTP MCP server.

Setup

Connection steps

01

Activate IDA library

uv run "/Applications/IDA Professional 9.4.app/Contents/MacOS/idalib/python/py-activate-idalib.py"
02

Install dependencies

cd ida-pro-mcp
uv sync
03

Install the IDA plugin

pip install https://github.com/mrexodia/ida-pro-mcp/archive/refs/heads/main.zip
ida-pro-mcp --install
04

Choose transport

Select Streamable HTTP (recommended) and Global (user-level).

05

Configure Codex in VS Code

{
  "mcpServers": {
    "ida-pro-mcp": {
      "type": "http",
      "url": "http://127.0.0.1:13337/mcp"
    }
  }
}
Troubleshooting

Common issues

No MCP tool available

Check that IDA is running, the database is open, and the server is listening on 127.0.0.1:13337.

Connection refused

Run this check in your terminal:


curl http://127.0.0.1:13337/mcp

Python mismatch

Activate the correct IDA Python library with py-activate-idalib.py.
